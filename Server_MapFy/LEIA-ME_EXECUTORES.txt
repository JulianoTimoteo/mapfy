================================================================================
          MAPFY 2026 - ORDEM DE EXECUCAO DO SERVIDOR (COMPUTADOR A)
                         Usina Pitangueiras - Safra 2026
================================================================================

Esta pasta contem estritamente a subpasta [server\] e os 4 executores oficiais
numerados em ordem recomendada de operacao e teste:

--------------------------------------------------------------------------------
1. 1_INICIAR_SERVIDOR_24_7 (.exe ou .bat)
--------------------------------------------------------------------------------
   - Inicia o servico central integrado do MapFy 2026:
       * Watchdog Guardiao (monitora a integridade e reinicia se cair)
       * API Gateway Local (FastAPI na porta 8000)
       * Extrator Incremental periodico de relatorios da Usina
       * Publicador automatico no GitHub Pages (live_data)
   - Fallback autonomo: se este computador nao tiver Python instalado,
     o executavel aciona automaticamente o binario compilado:
     server\MapFyServer.exe (com runtime embutido).
   - De dois cliques para iniciar a operacao cont?nua do servidor.

--------------------------------------------------------------------------------
2. 2_INICIAR_SENTINEL_AGENT (.exe ou .bat)
--------------------------------------------------------------------------------
   - Inicia o agente de telemetria independente (Heartbeat).
   - Envia batimentos criptografados (HMAC-SHA256) a cada 60 segundos
     para o Computador B (MapFy Sentinel).
   - Caso o servidor MapFy fique indisponivel por mais de 120 minutos,
     o Computador B dispara alarme critico para o Juliano via WhatsApp
     (+5516992886004) e Telegram.
   - De dois cliques para iniciar o monitoramento externo.

--------------------------------------------------------------------------------
3. 3_INICIAR_EXTRATOR (.exe ou .bat)
--------------------------------------------------------------------------------
   - Executa uma extracao manual avulsa dos relatorios imediatamente.
   - Util para testar a conexao de download ou forcar a atualizacao
     pontual das planilhas sem esperar o ciclo agendado.

--------------------------------------------------------------------------------
4. 4_EXECUTAR_TESTES (.exe ou .bat)
--------------------------------------------------------------------------------
   - Executa a suite automatizada de testes unitarios em server\tests\.
   - Valida 100% da integridade: API Gateway, Extrator, Publicador GitHub,
     rotas de mapas de talhoes (/api/v1/maps/shapes e /api/v1/maps/manifest).
   - Util para homologar que o ambiente esta perfeitamente operacional.

================================================================================
* Ferramentas complementares estao arquivadas em: server\ferramentas\
  (CONFIGURAR_PYTHON para setup do venv e INICIAR_GATEWAY avulso).
================================================================================
